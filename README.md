# Panachaiko Trails

Διαδραστικός χάρτης παρουσίασης και εξερεύνησης μονοπατιών στο Παναχαϊκό όρος.

Η πρώτη φάση περιλαμβάνει τα 13 μονοπάτια του αρχικού prototype, Leaflet χάρτη,
λίστα διαδρομών και βασικές πληροφορίες ανά μονοπάτι. Τα δεδομένα βρίσκονται
προσωρινά στο `src/data/trails.json` και θα αντικατασταθούν από το Headless
WordPress API σε επόμενη φάση.

## Ανάπτυξη

```sh
npm install
npm run dev
```

## Παραγωγή

```sh
npm run build
npm run preview
```
