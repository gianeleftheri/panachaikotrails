## Homepage WordPress controls

New CMS module:
`wordpress/panachaiko-trails-cms/includes/class-panachaiko-homepage.php`

Administrator + Editor can configure:
- number of latest entries shown per panel (1–12),
- blog category for the Home panel,
- background photo for each panel from WordPress Media Library.

Recommended panel background:
- 1800×1200 px or larger,
- WebP/JPEG,
- ideally <= 1.5 MB.

Panels:
1. Home / Blog
2. Trails
3. Points of Interest
4. Shelters
5. Photos
6. Video

Data sources:
- Home: WordPress posts, newest first, optional category filter.
- Trails: latest published `trail` posts.
- Points of Interest: latest published `trail_poi` with content_type=note, excluding shelter POIs.
- Shelters: latest published `trail_poi` with poi_type=shelter.
- Photos: latest published `trail_poi` with content_type=photo.
- Video: latest published `trail_poi` with content_type=video.

Existing static panel photos remain as fallback when no CMS image is configured or CMS is unavailable.
