# Panachaiko Trails — Admin UI (v0.7.2)

Ανεξάρτητο πρόσθετο για **το WordPress στο `cms.panachaikotrails.gr`**. Δεν επεμβαίνει σε WordPress core, στο υπάρχον `panachaiko-trails-cms` ή στη δημόσια Astro ιστοσελίδα.

## Full-screen / responsive έκδοση

- Η αρχική του CMS για μη συνδεδεμένους επισκέπτες καλύπτει ολόκληρο το viewport, χωρίς κάρτα ή λευκά περιθώρια. Το WordPress admin dashboard αξιοποιεί **ολόκληρο τον διαθέσιμο χώρο δίπλα στο κανονικό αριστερό μενού** — το μενού δεν κρύβεται.
- Μεγάλος τίτλος «ΠΑΝΑΧΑΪΚΟ / TRAILS», η επιλεγμένη εικονογράφηση, navy/blue/lime/orange, μεγάλα τυπογραφικά στοιχεία και mobile/tablet/desktop breakpoints.
- Τέσσερις δυναμικές ενδείξεις: **δημοσιευμένες διαδρομές**, **συνολική απόσταση (χλμ.)**, **μέγιστο υψόμετρο *δημοσιευμένων διαδρομών* (μ.)**, **συνολική ανάβαση (μ.)**. Διαβάζονται από τα ήδη υπάρχοντα WordPress meta fields `length_km`, `elev_max`, `gain_m` μόνο σε `trail` με status `publish`. Δεν είναι live μετρήσεις, κορυφή Παναχαϊκού ή επινοημένα demo στατιστικά. Ελλείποντα στοιχεία εμφανίζονται ως «—».
- Κάρτες με πραγματικά counts άρθρων/διαδρομών/POI/media, πρόσφατες εγγραφές και ενεργούς συνδέσμους WordPress.
- Διατηρείται το κανονικό WordPress login, τα δικαιώματα και το REST API.

## Εγγραφή πεζοπόρων

- Η διεύθυνση `/?pt_action=submit_trail` εμφανίζει ενιαία πύλη σύνδεσης και δημιουργίας λογαριασμού.
- Οι νέοι λογαριασμοί δημιουργούνται αποκλειστικά ως `subscriber`, χωρίς δικαίωμα δημοσίευσης ή διαχείρισης.
- Η εγγραφή απαιτεί ονοματεπώνυμο, έγκυρο email, κινητό, κωδικό τουλάχιστον 10 χαρακτήρων και ρητή συγκατάθεση.
- Η επιβεβαίωση email γίνεται με token μίας χρήσης που αποθηκεύεται ως hash και λήγει σε 24 ώρες.
- Περιλαμβάνονται nonce, honeypot και βασικός περιορισμός επαναλαμβανόμενων προσπαθειών.
- Για πραγματική αποστολή επιβεβαιώσεων απαιτείται σωστά ρυθμισμένο WordPress email/SMTP.

## Υποβολή νέου μονοπατιού

- Ο διακόπτης **Panachaiko Trails → Κατάσταση Site → Προσθήκη μονοπατιού από επισκέπτες** είναι κλειστός από προεπιλογή. Όσο παραμένει κλειστός, η δημόσια πύλη δείχνει ενημερωτικό μήνυμα και απορρίπτονται ακόμη και απευθείας αιτήματα εγγραφής ή υποβολής. Οι διαχειριστές μπορούν να συνεχίσουν να δημιουργούν διαδρομές μέσα στο WordPress. Απαιτείται το `panachaiko-trails-cms` v0.4.5 ή νεότερο για την ενεργοποίηση.

- Μόνο συνδεδεμένοι χρήστες με επιβεβαιωμένο email μπορούν να υποβάλουν διαδρομή. Οι διαχειριστές εξαιρούνται για δοκιμές.
- Η απλή φόρμα ζητά όνομα, περιγραφή και ονομασία αφετηρίας/τερματισμού.
- Ο χρήστης επιλέγει είτε αρχείο GPX έως 5 MB είτε σχεδίαση της διαδρομής με διαδοχικά σημεία πάνω σε διαδραστικό χάρτη.
- Η σχεδίαση υποστηρίζει εντοπισμό θέσης, αναίρεση τελευταίου σημείου, καθαρισμό και ζωντανή εκτίμηση απόστασης.
- Η τρίτη επιλογή **Καταγραφή με GPS** χρησιμοποιεί το GPS του κινητού με έναρξη, παύση, συνέχεια και τερματισμό.
- Στίγματα με ακρίβεια χειρότερη από 60 μέτρα δεν προστίθενται στη διαδρομή και διαδοχικά σημεία πρέπει να απέχουν τουλάχιστον 5 μέτρα.
- Η ενεργή καταγραφή αποθηκεύεται προσωρινά στη συσκευή και μπορεί να επαναφερθεί για έως 7 ημέρες.
- Ζητείται screen wake lock όπου υποστηρίζεται, αλλά η web εφαρμογή δεν εγγυάται συνεχή GPS καταγραφή όταν η οθόνη κλειδώσει ή το πρόγραμμα περιήγησης περάσει στο παρασκήνιο.
- Το GPX αναλύεται στον διακομιστή χωρίς να εκτελείται ή να δημοσιεύεται. Επιτρέπονται έως 50.000 έγκυρα σημεία.
- Υπολογίζονται αυτόματα γεωμετρία MultiLineString, μήκος, ελάχιστο/μέγιστο υψόμετρο, ανάβαση, κατάβαση και συντεταγμένες Α→Τ.
- Η νέα εγγραφή αποθηκεύεται ως `trail` με κατάσταση `pending` και `trail_stage=investigation`.
- Ο χρήστης βλέπει τις δικές του υποβολές και την κατάστασή τους: υπό έλεγχο, χρειάζεται επεξεργασία, εγκρίθηκε ή απορρίφθηκε.
- Δεν αλλάζει ο κώδικας ή το μοντέλο δεδομένων του `panachaiko-trails-cms`.

## Εγκατάσταση και rollback

Δημιούργησε ZIP με ριζικό φάκελο `panachaiko-trails-admin-ui` και εγκατάστησέ το από **Πρόσθετα → Προσθήκη νέου → Μεταφόρτωση πρόσθετου**. Για αναβάθμιση του ήδη εγκατεστημένου v0.1.0, αντικατάστησε το προηγούμενο ZIP μέσω του WordPress update/replace plugin workflow αφού πάρεις backup. Μπορείς να απενεργοποιήσεις το πρόσθετο για άμεσο rollback χωρίς να διαγραφούν οι διαδρομές.

Στο GitHub υπάρχει ελαφρύ SVG fallback `assets/hero-panachaiko.svg`. Για την ακριβή εγκεκριμένη εικονογράφηση, τοποθέτησε `assets/hero-panachaiko.webp` στον ίδιο φάκελο πριν δημιουργήσεις το ZIP — τότε επιλέγεται αυτόματα. Το ξεχωριστό ZIP παραδοτέο της συνομιλίας περιλαμβάνει ήδη το WebP.

**Το merge στο GitHub ΔΕΝ εγκαθιστά αυτομάτως αλλαγές στο live WordPress.** Το workflow παράγει μόνο ZIP artifact. Η παραγωγική εγκατάσταση/ενεργοποίηση και ο έλεγχος σε πραγματικές διαστάσεις οθόνης είναι ξεχωριστά βήματα.
