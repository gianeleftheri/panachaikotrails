# Panachaiko Trails — Admin UI (v0.1.0)

Ανεξάρτητο πρόσθετο για **το WordPress στο `cms.panachaikotrails.gr`**. Δεν επεμβαίνει στα αρχεία πυρήνα του WordPress και δεν αντικαθιστά το υπάρχον `panachaiko-trails-cms` plugin.

## Πρώτες αλλαγές

- Νέο διαχειριστικό μενού **Panachaiko Trails** με branded dashboard.
- Hero με κορυφογραμμή, καταφύγιο, μονοπάτι και ορειβάτη· βασικά χρώματα μπλε, navy, lime, πορτοκαλί.
- Πραγματικοί αριθμοί από εγγραφές WordPress για άρθρα, διαδρομές, σημεία και πολυμέσα. Δεν υπάρχουν επινοημένα analytics.
- Γρήγοροι σύνδεσμοι προς πραγματικές σελίδες δημιουργίας και επεξεργασίας.
- Διακριτικό styling του υπάρχοντος αριστερού admin menu και της σελίδας εισόδου.
- Μόνο στο `cms.panachaikotrails.gr`, η αρχική σελίδα εμφανίζει ιδιωτική branded είσοδο στους επισκέπτες και ανακατευθύνει τους συνδεδεμένους editors/admins στο νέο dashboard.

## Εγκατάσταση

Δημιούργησε ZIP με ριζικό φάκελο `panachaiko-trails-admin-ui` και εγκατάστησέ το από **Πρόσθετα → Προσθήκη νέου → Μεταφόρτωση πρόσθετου → Ενεργοποίηση**. Εναλλακτικά μπορείς να αντιγράψεις τον φάκελο στο `wp-content/plugins/`.

Το αποθετήριο περιέχει ένα ελαφρύ SVG fallback στο `assets/hero-panachaiko.svg`. Για την εγκεκριμένη εικονογράφηση, πρόσθεσε στο ίδιο `assets/` το αρχείο `hero-panachaiko.webp` (το έτοιμο ZIP που δημιουργήθηκε στη συνομιλία το περιλαμβάνει). Το plugin το επιλέγει αυτόματα όταν υπάρχει.

**Δεν υπάρχει αυτοματοποιημένη εγκατάσταση στο live WordPress από το GitHub workflow.** Το workflow παράγει ZIP artifact· η εγκατάσταση και ενεργοποίηση στο CMS είναι ξεχωριστό βήμα. Δεν αλλάζει η δημόσια Astro ιστοσελίδα `panachaikotrails.gr`.

Για απενεργοποίηση/rollback: **Πρόσθετα → Panachaiko Trails — Admin UI → Απενεργοποίηση**. Όλα τα δεδομένα και οι διαδρομές παραμένουν ως έχουν.
